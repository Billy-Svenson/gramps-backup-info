# Gramps Backups

Gramps Backups is a personal tool used by its owner to back up
a private Gramps Web family tree.

The tool uses Google Drive access to upload backup archives,
verify them, and remove expired backups according to the owner's
retention settings. It is not offered as a public service.

Family records and backup archives are private and are not
published on this website.
